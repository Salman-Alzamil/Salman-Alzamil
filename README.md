# Salman Alzamil

AI engineer in Riyadh. I build retrieval and LLM systems, computer vision models, and the web and mobile apps that use them. B.Sc. in Computer Science from Imam Mohammad Ibn Saud Islamic University.

## Projects

### [Mirqat](https://github.com/Salman-Alzamil/mirqat)
Arabic and English question answering over Hanbali fiqh, hadith and modern Saudi fatwa collections. Every answer cites the book, volume and page it came from. Live at [mirqat.app](https://mirqat.app).

### [Diala](https://github.com/Salman-Alzamil/diala)
A personal AI assistant you can message or talk to out loud. It searches the web, remembers your preferences and works with apps you connect, asking you before it changes anything.

### [Freelance work](https://github.com/Salman-Alzamil/freelance-work)
Two platforms in production for clients. One handles program registration and online payments for a community association. The other is a finance system that reads invoices with a vision model, built for an education consultancy.

### [Marrow](https://github.com/Salman-Alzamil/marrow)
A mobile app that takes a shared TikTok, Instagram or YouTube link and turns it into a recipe, workout or travel plan.

I also run a multi-agent system on my own machine that handles research and scheduled reporting.
